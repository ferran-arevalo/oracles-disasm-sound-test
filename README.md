# oracles-disasm-sound-test
You can freely listen to all Ages's (or Seasons's) music and sound effects! If you've made some custom music, you can use this to create a Sound Test with your own tracks!

## Controls

  **-D-Pad Up/Down:** Switch between the Music list and the SFX list.

  **-D-Pad Left/Right:** Navigate through the list.


  **-A button:** Play the selected Music or SFX (or stop the music currently being played).
	
  **-B button:** Stop all sounds with a fadeout.

## Custom music
  
  If you want to add custom music to this Sound Test, you can just add it how you would normally do for any other romhack, and then write your song's name in the text.yaml file
  (all audio names are written in text indices TX_09XX, where XX is the audio index).
